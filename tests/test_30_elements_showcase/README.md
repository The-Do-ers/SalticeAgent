## 🔬 Core Technologies & Elements (30 Total)

1. **GSAP 3 & Lenis Motion**: Lenis smooth scroll ticker binding, top scroll progress bar, staggered kinetic 3D title, pinned horizontal module rail, multi-depth parallax grids, dynamic number tickers.
2. **React Bits Micro-Interactions**: Matrix decrypted cyber text, mouse-proximity particle wave canvas, spotlight cards with radial glow halos, magnetic physics buttons, shiny metallic shimmer badges, 3D tilt perspective cards, custom trailing neon cursor, blur-to-sharp text reveal.
3. **Kokonut UI Components**: Floating Dynamic Island dock with spring tooltips, `Cmd+K` AI command bar modal, asymmetric Bento Grid, live status radar beacon pill, segmented tab slider, spring toggle switches, floating speed dial menu, parameter scrub slider.
4. **Creative Web Design & Editorial**: Procedural SVG film grain overlay, Danilo De Marco monumental typography, Ollivere stacked card deck, infinite kinetic marquee ribbon, technical accordion drawers, Web Audio API procedural cyber click/hum synthesis, blueprint schematic modal, circular scroll-to-top progress indicator.

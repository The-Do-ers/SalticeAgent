# ORBITAL DYNAMICS - Aerospace Telemetry Lab Walkthrough

## Getting Started

1. **Open the Application**:
   - Open `index.html` in a modern web browser
   - The application will load automatically

## User Interface Overview

### Main Viewport

1. **Header Section**:
   - Displays the application title with decrypted text effect
   - Shows status badges indicating system status

2. **Orbital Canvas**:
   - Central view showing the orbital system
   - Features a verified vector asset for the central body
   - Displays multiple satellites in orbit

3. **Bento Grid**:
   - Four interactive cards showing different telemetry data
   - Satellite Orbit: Real-time orbital parameters
   - Velocity Vector: Instantaneous velocity components
   - Apogee/Perigee: Extreme orbital points telemetry
   - Gravity Well: Central body gravitational influence

### Dynamic Island Control Dock

Located at the bottom of the screen:

1. **Telemetry Toggle**: View real-time telemetry data
2. **Orbit Zoom**: Adjust the zoom level of the orbital view
3. **Gravity Well**: Toggle the gravity well interaction
4. **Sound Synth**: Enable/disable sound effects

## Interactive Features

### Orbital Canvas

1. **Mouse Interaction**:
   - Move your mouse to interact with the gravity well
   - Satellites will respond to your mouse position

2. **Gravity Well**:
   - Click the Gravity Well button in the control dock
   - Satellites will be attracted to your mouse position

### Control Dock

1. **Telemetry Toggle**:
   - Click to view detailed telemetry data in the bento cards

2. **Orbit Zoom**:
   - Adjust the zoom level of the orbital view

3. **Gravity Well**:
   - Toggle the gravity well interaction

4. **Sound Synth**:
   - Enable/disable sound effects for button clicks and gravity well activation

## Troubleshooting

If you encounter any issues:

1. **White Screen**:
   - Ensure you're using a modern web browser
   - Check the browser console for errors

2. **Performance Issues**:
   - Close other applications to free up system resources
   - Try reducing the number of satellites in the orbital system

3. **Sound Not Working**:
   - Ensure your browser allows audio playback
   - Check your system audio settings

## Conclusion

The ORBITAL DYNAMICS - Aerospace Telemetry Lab provides an interactive and educational experience for exploring orbital mechanics and aerospace telemetry. The intuitive interface and engaging features make it an excellent tool for learning about orbital dynamics and aerospace engineering concepts.

# AETHER LABS — Creative Agency Web Showcase

An avant-garde digital design & creative development studio web application built with **GSAP**, **Lenis**, **React Bits**, and **Kokonut UI**.

---

## ⚡ Quickstart

Open [`index.html`](file:///d:/USEME%20FOLDER/ANTIGRAVITY/test_creative_showcase/index.html) directly in any modern browser, or serve locally:

```powershell
npx serve "d:\USEME FOLDER\ANTIGRAVITY\test_creative_showcase" -p 3000
```
Then visit `http://localhost:3000`.

---

## 🚀 Key Features

1. **Inertial Smooth Scrolling (Lenis 1.1.18 + GSAP 3.12.5)**
   - High-precision ticker synchronization.
   - Pinned horizontal showcase section scrubbing project cards across the viewport.

2. **Kinetic Typography (Danilo De Marco Style)**
   - Staggered character entrance for `"BEYOND THE HORIZON"` with spring easing.
   - Live matrix character decryption on hover with React Bits.

3. **Interactive Physics & Micro-Interactions**
   - Cursor-proximity canvas dot grid reacting in real-time.
   - Dynamic spotlight cards with radial glow borders tracking mouse coordinates.

4. **Kokonut UI Components**
   - Dynamic Island bottom floating dock with spring physics.
   - AI prompt synthesis command bar.
   - Bento grid capability cards.

5. **Editorial Aesthetics**
   - Procedural SVG film grain overlay.
   - Ollivere stacked card deck that pins and scales down on scroll.
   - High-contrast obsidian, cyan, and silver palette.
